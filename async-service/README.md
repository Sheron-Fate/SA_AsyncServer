# Асинхронный сервис для обработки заявок на спектральный анализ

Django сервис для выполнения асинхронных расчетов процентов пигментов.

## Установка

1. Создать виртуальное окружение:
```bash
python -m venv env
source env/bin/activate  # Linux/Mac
# или: env\Scripts\activate  # Windows
```

2. Установить зависимости:
```bash
pip install -r requirements.txt
```

3. Применить миграции (опционально, для базового функционала не требуется):
```bash
python manage.py migrate
```

## Запуск

```bash
python manage.py runserver 7070
```

Сервис будет доступен на `http://localhost:7070`

## API

### POST /api/async/process-analysis

Запускает асинхронную обработку заявки.

**Тело запроса:**
```json
{
  "analysis_id": "uuid-заявки"
}
```

**Ответ (сразу):**
```json
{
  "status": "ok",
  "message": "Обработка заявки {analysis_id} запущена"
}
```

Обработка происходит в фоне с задержкой 5-10 секунд. После завершения результаты автоматически отправляются в основной сервис на эндпоинт `POST /api/spectrum-analysis/:id/update-results`.

## Архитектура

- Использует `ThreadPoolExecutor` для фонового выполнения задач
- После завершения расчета вызывает колбэк `result_callback`
- Колбэк отправляет результаты в основной сервис через HTTP API
- Ключ-токен для псевдо-авторизации: `secret12345678`
